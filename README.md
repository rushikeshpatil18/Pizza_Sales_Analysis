# Pizza_Sales_Analysis

📌 Business Problem

The pizza business wants to understand its sales performance
and identify opportunities to improve revenue and customer demand.

The analysis aims to answer questions such as:

- How many orders and pizzas were sold?
- What is the total revenue?
- Which pizzas are ordered the most?
- Which pizzas generate the highest revenue?
- Which pizza categories contribute the most revenue?
- What are the busiest ordering hours?
- How does revenue change month by month?
- Which pizza types perform best within each category?

## 🛠 Tools Used

- MySQL
- Power BI
